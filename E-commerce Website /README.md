### 🎯 Techniques Demonstrated
- **Boundary Value Analysis:** Password length tested at 7 (fail), 8 (pass), 9 (pass)
- **Positive & Negative Testing:** Valid inputs vs invalid/missing inputs
- **Traceability:** Every failed test case linked to its bug report (e.g., TC_008 → BUG_001)
